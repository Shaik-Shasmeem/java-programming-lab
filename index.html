Conclusion

Java, C, C++, Python, and JavaScript each serve different purposes. C and C++ excel in system programming and high-performance applications. Java is widely used for enterprise and Android development because of its portability and security. Python is preferred for artificial intelligence, automation, and data science due to its simplicity and extensive libraries. JavaScript dominates web development by enabling interactive client-side and server-side applications. Selecting the right language depends on project requirements such as performance, scalability, ease of development, and platform support.

Java Installation and Hello World

Installing Java on Windows with OpenJDK and with Oracle JDK, setting JAVA_HOME and PATH, and compiling and running a first program.

Installation of Java and Execution of a Simple Hello World Program (Windows) in OpenJDK

Installing and configuring OpenJDK

Software Required
  • Windows Operating System
  • Internet Connection
  • OpenJDK
  • Command Prompt

Step 1: Download OpenJDK

  1. Open any web browser.
  2. Visit the official OpenJDK website or Eclipse Adoptium website.
  3. Download the latest stable OpenJDK for Windows (64-bit).

Step 2: Install OpenJDK

  1. Double-click the downloaded installer.
  2. Follow the installation wizard.
  3. Choose the installation location if required.
  4. Click Install and wait until the installation is completed.
  5. Click Finish.

Step 3: Configure Java Environment Variables

Set JAVA_HOME

  1. Press Windows + R, type sysdm.cpl, and press Enter.
  2. Open the Advanced tab.
  3. Click Environment Variables.
  4. Under System Variables, click New.
  5. Enter the following:
Variable Name:  JAVA_HOME
Variable Value: (Example)
C:\Program Files\Eclipse Adoptium\jdk-21

(Use the path where OpenJDK is installed on your system.)

Update the PATH Variable

  1. Under System Variables, select Path.
  2. Click Edit.
  3. Click New.
  4. Add: %JAVA_HOME%\bin
  5. Click OK to save all the changes.

Step 4: Verify the Installation

  1. Open Command Prompt.
  2. Type: java --version
Sample Output
Output
openjdk 26.0.1
  1. Now check the Java compiler: javac --version
Sample Output
Output
javac 26.0.1

Execution of a Simple Hello World Program

Configuring Java on Windows (Setting JAVA_HOME and PATH)

Step 1: Find Java Installation Path

After installing Java, locate the JDK folder.

Example:

Step 2: Set JAVA_HOME

  1. Press Windows + R → Type sysdm.cpl → Press Enter.
  2. Select Advanced tab.
  3. Click Environment Variables.
  4. Under System Variables, click New.

Enter:

Variable Name : JAVA_HOME
Variable Value: C:\Program Files\Java\jdk-25.0.3
  1. Click OK.

Step 3: Update PATH Variable

  1. Under System Variables, select Path.
  2. Click Edit.
  3. Click New.
  4. Add: %JAVA_HOME%\bin
  5. Click OK → OK → OK.

Step 4: Verify Configuration
