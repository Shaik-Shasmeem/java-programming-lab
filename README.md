# Java Programming Lab

My laboratory record for **Object-Oriented Programming through Java Lab (24CS202)**, built as a single-page website.

**Live site:** https://shaik-shasmeem.github.io/java-programming-lab/

## Contents

| # | Section | Covers |
|---|---|---|
| 01 | Language Comparison | Java, C, C++, Python and JavaScript compared; most suitable language by requirement |
| 02 | Java Installation | OpenJDK and Oracle JDK on Windows, `JAVA_HOME` and `PATH`, Hello World |
| 03 | Basic Java Programs | Programs 1–15: data types, operators, type conversion, control statements, loops |
| 04 | OOP Experiments | Experiments 1–14: classes, objects, constructors, `this`, overloading, `static`, `final`, nested and inner classes |
| 05 | Strings & Introductory Inheritance | Experiments 1–5: `String`, `StringBuffer`, `StringTokenizer`, inheritance, `super` |
| 06 | Inheritance Programs | Programs 1–10: single and multilevel inheritance, overriding, dynamic method dispatch |
| 07 | Exception Handling | Experiments 1–10: `try`/`catch`, `throw`, `throws`, `finally`, custom exceptions |
| 08 | I/O: Byte Streams | Experiments 1–5: byte array and file streams, copying files |
| 09 | Character Streams & Thread Basics | Experiments 1–12: `FileReader`/`FileWriter`, creating threads, `isAlive()`, `join()` |
| 10 | Multithreaded Programming & Lambda Expressions | Experiments 1–15: thread priorities, synchronization, race conditions, lambdas, generic functional interfaces |

Each experiment shows its source code and output. Programs 1–15 in Section 03 show their output screenshots.

## Features

- One page with a sidebar that tracks where you are while you scroll
- A copy button on every code block
- Works on desktop and mobile
- Plain HTML, CSS and JavaScript, with no frameworks, build step or external libraries

## Files

```
index.html   the full record (screenshots are embedded in the page)
style.css    all styles
```

## Viewing it locally

Download or clone the repository and open `index.html` in any browser. It works offline.
